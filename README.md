# Цели и награды — сайт + приложение для Android

Ставишь себе набор целей, за каждую — монеты и (по желанию) своя награда.
За выполнение **всех** целей — главный приз. Если выполнено **не всё**, правило настраивается в каждом наборе:

- **По доле** — часть главного приза пропорционально выполненному (например, 7 из 10 → 70% монет), если сделано не меньше минимального процента;
- **По порогу** — фиксированный утешительный приз, если выполнено не меньше N%;
- **Ничего** — бонус только за 100%.

Монеты тратятся в «Магазине наград», который вы наполняете сами (кино, пицца, покупка…).

## Что в архиве

```
web/        — сайт (index.html + иконки + офлайн‑режим)
android/    — приложение Android (WebView с тем же сайтом внутри, работает без интернета)
.github/    — автосборка: GitHub сам собирает APK и выкладывает сайт с кнопкой «Скачать»
keystore/   — ваш ключ подписи APK. НЕ загружайте в репозиторий!
```

## Как запустить (≈10 минут, бесплатно)

1. Создайте репозиторий на GitHub и загрузите туда всё, **кроме папки `keystore/`**
   (проще всего: «Add file → Upload files», перетащить папки `web`, `android`, `.github`, файлы `README.md` и `.gitignore`).
   Папка `.github` скрытая — если её не видно, включите показ скрытых файлов.
2. **Settings → Pages → Source: GitHub Actions.**
3. **Settings → Secrets and variables → Actions** — добавьте 4 секрета из файла `keystore/СЕКРЕТЫ_ДЛЯ_GITHUB.txt`.
   (Можно пропустить — APK соберётся с отладочным ключом, но тогда новые версии не будут ставиться поверх старой.)
4. Вкладка **Actions → «Собрать APK и опубликовать сайт» → Run workflow** (или просто сделайте любой коммит в `main`).
5. Через 3–5 минут сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`,
   а кнопка «Скачать» на нём будет отдавать свежий `app.apk`.

На телефоне: скачать APK → открыть → разрешить «Установку из неизвестных источников» для браузера.

## Как это устроено

- Данные хранятся на устройстве (localStorage). Сайт и приложение хранят их отдельно; перенос — через «Ещё → Резервная копия».
- Любая правка `web/index.html` → коммит → GitHub пересоберёт и сайт, и APK.
- Собрать APK локально: Android Studio → Open → папка `android`, предварительно скопировав `web/index.html` и `web/icons` в `android/app/src/main/assets/www/`.
